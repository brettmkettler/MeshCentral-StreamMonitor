# Changelog

All notable changes to the MeshCentral Stream Monitor Plugin will be documented in this file.

## [0.1.0] - 2024-11-16

### Added
- Initial release of Stream Monitor Plugin
- Groq multimodal LLM integration for activity analysis
- Periodic screenshot capture from monitored devices
- Confidence-based activity detection and reporting
- REST API for monitoring control
- Configuration management via API
- Activity logging and reporting
- Backend hooks for device connection events
- Support for multiple concurrent device monitoring
- Configurable monitoring intervals and thresholds

### Features
- AI-powered activity detection using Groq's vision models
- Real-time stream monitoring capabilities
- Automated screenshot analysis
- Threshold-based alert system
- Device status tracking
- Comprehensive logging system
